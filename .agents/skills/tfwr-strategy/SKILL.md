# TFWR Strategy

Save0 的策略权威概览。改种植、收获、走位或迷宫门槛时先读本文，再改 `Saves/Save0`。

实现细节：`/tfwr-farm` 的 [farm-layout.md](../tfwr-farm/references/farm-layout.md)。方言：`/tfwr-farm`。解锁：`/tfwr-save`。

只维护 `.agents/skills/`。

## 总目标

把可种作物的 **数量 × VALUE** 拉到同一水平。低于保底的永远优先。一波只选一个模式，整块田归它，不再切三块混种。

Power `< 500`：强制向日葵，打断南瓜/仙人掌轮次锁。Power `< 16000`：向日葵仍进候选，种上后锁到本波能收的档位结束。只剩 10 朵才放锁。当前档没熟就地施肥催熟，保持 hold，不要放锁补种。骨头资产（数量 × 80）更穷、Power ≥ 500、仙人掌够买约一边长颗苹果：上恐龙。清场戴帽后走偶边长哈密顿圈，并只朝苹果方向抄近路（邻居必须在当前→苹果的圈弧上）。不要纯跟圈（太慢），也不要贪心曼哈顿（横切尾巴）。走不动或没苹果了再摘帽拿 `n²`，直到骨头不再比南瓜/仙人掌穷。这一波只 `clear()` 一次。不跨波锁。否则在南瓜 / 仙人掌 / 草木胡萝卜里选最穷的。向日葵占整田，按花瓣档位从高到低多人收，至少留 10 朵拿 8 倍；档位没收完不要补种。

金子和奇异物质不种、不进 `pick_mode`。奇异物质跟作物最小资产比，穷才施肥。刷金只跑 `main_maze`，不要用金子资产决定开不开迷宫。

## 两种模式

**农场**：`run_mode` 只 `pick_mode` 再调模块 `run()`。向日葵/南瓜/仙人掌各自整田种完再收；草木胡萝卜种完补 `get_companion` 伴侣。恐龙单机清场戴帽，不发工人。不读金子、不开迷宫。

**迷宫**：执行 `main_maze`。种灌木后开迷宫，分叉处 spawn，满员则 DFS 回溯。只收宝藏。其它无人机退出后再 `clear()`。排错先读工程根 `output.txt`。

## 资产口径

| 东西 | VALUE | MIN | 进 pick_mode | 下种 |
| --- | ---: | ---: | --- | --- |
| 草 | 2 | 2000 | 是 | 是 |
| 木 | 8 | 2000 | 是 | 是 |
| 胡萝卜 | 40 | 800 | 买得起才进 | 是 |
| 南瓜 | 80 | 无 | 是 | 是 |
| Power | 40 | 500 | 是（向日葵，上限 16000） | 向日葵 |
| 仙人掌 | 80 | 无 | 买得起才进 | 是 |
| 骨头 | 80 | 无 | 更穷且仙人掌够买苹果才进 | 恐龙帽 |
| 奇异物质 | 80 | 无 | 否 | 否（施肥产） |
| 金子 | 80（仅迷宫） | 无 | 否 | 否 |

得分：`-(数量 × VALUE)`；数量低于 MIN 再加 `1000000000`。资产越小越该种。

`min_crop_wealth()` 只含可种作物，避免金子/奇异物质自己比自己。

胡萝卜要草/木；仙人掌看 `get_cost(Entities.Cactus)`。买不起就不进候选。

## 按格布局

`tile_plan[x][y]` 是种植/收获/施肥的依据。`column_plan[x]` 只表示该列主作物。一波一个模式，布局是从 `(0,0)` 起的单矩形，剩余格铺草。

原点 `pick_mode()` 只选一种作物：

- 向日葵：Power `< 16000` 可进候选；低于 500 强制上场。这一波占整田。
- 仙人掌：整田排序再收，产量是数量平方。不要再按工人数缩成小矩形。
- 南瓜：独占整田。对角 `measure()` 同一个 ID 再收合体。
- 草木胡萝卜：独占整田。树按 `(x+y)%2` 棋盘格。种下后 `get_companion()`，本列顺手种，外列交回主无人机。
- 恐龙：骨头更穷且仙人掌够买苹果时上场。`clear()` 戴帽后走哈密顿圈并朝苹果抄近路，满田或没苹果再摘帽拿 `n²`。不跨波锁。

南瓜/仙人掌轮次未收完不换模式、不改矩形。向日葵只剩 10 朵才放锁。Power `< 500` 打断锁，改种向日葵。不要再把三种特殊作物画回同一圈。

## 向日葵

Power ≥ 16000 才不进 `pick_mode`。低于 16000 占整田。工人种下立刻 `measure()`，花瓣写进 `sunflower_box`。扫列时只测不收。

官方口径：至少 10 朵且收当前最大花瓣是 **8 倍**。田里还有更高花瓣时收低档，后面也没倍数。先收完当前最大档（所有 15，再所有 14）。档位没收完不要补种。收过的格会变草，这是洞不是种错。工人内存是拷贝，收成看交回格子数。花瓣用 hist，不要收一朵就整表 `recompute`。工人只走到本档的 y，发完最后一列先 `go_to(0,0)` 再 `wait_for`，不要停在右下角。当前档未熟就地施肥（最多 3 次），保持 hold。不要每档 `print sun_tier`（停 1 秒）。只剩 10 朵才 `end_sunflower_lock`。hold 之后 `known < expected` 是收过的洞，不要当表不齐直接 return。不要用 9 档封顶。排错先跑 `/tfwr-control` 的 `parse`。不要按列收光、也不要单机一朵一补种。

## 南瓜

坏南瓜立刻补种。本块计划格都是成熟活南瓜，且对角 `measure()` 同一个 ID，再收合体（产量是这块立方）。不要收零散小合体。轮次未收完不换模式。不要拆未合体活南瓜。

## 仙人掌

整田排序再收。仙人格上的南瓜先收再补仙人掌，不要留下。成熟后才记尺寸、才 swap；邻格不是仙人掌或未成熟不要换。列上多人南北换，行上多人东西换，整田有序再收到西南角 `(0,0)`，产量是数量的平方。

## 恐龙

单机。官方：苹果花仙人掌；尾巴占走过的格，`move` 上尾巴会失败，尖端会让开；戴帽不环绕。纯跟圈平均走 `size²/2` 才吃一颗，太慢；贪心曼哈顿横切尾巴。`clear()` 戴帽后走偶边长哈密顿圈，用 `measure()` 看下一颗，只走到圈下标在「当前→苹果」之间的邻居（折返相邻可跳）。走不动或没苹果再摘帽拿 `n²`。这一波只清一次场。不要 `go_to`、不要 `spawn_drone`、不要 `set_world_size`。摘帽 `print("dino", eaten, steps)`。

计划与实体对不上先清再种。花瓣只记向日葵计划格。仙人格不施肥。轮次锁整列宽度。

## 迷宫

只在 `main_maze` 开。这是刷金脚本，**不要用金子×80 跟作物比来决定开不开**（金已经高于 Power 资产时会立刻 `break`，看起来像「跑不了」）。

要开：迷宫已解锁、Power ≥ 500、奇异物质够（边长 × 2^(迷宫升级-1)）。清占格后种灌木再 `use_item`。分叉 spawn，只收宝藏。停机原因会 `print` 到工程根 `output.txt`。

## 肥料

奇异物质 × 80 低于作物最小资产才施。填料列看脚下格：南瓜/向日葵/仙人不施。向日葵**收当前最大档**时未熟可以施。不要对灌木用变异质，除非走迷宫模块。

## 走位

主无人机按列走到 `(x,0)` 再 spawn。世界环绕，`go_to` 走较短方向。每列都走，清掉上一波留下的作物。不要再跳过向日葵列或南瓜列。

## 改策略时动哪里

- 价值/保底/选模式：`Saves/Save0/plant_module.py` 的 `pick_mode`、`mode_rect`、伴侣
- 单矩形 / `tile_plan` / 圈级边长：`saved_data_module.py` 的 `apply_mode_layout`、`refresh_size`
- 填料收获：`harvest_module.py`；向日葵：`sunflower_module.run`；南瓜：`pumpkin_module.run`；仙人掌：`cactus_module.run`；恐龙：`dinosaur_module.run`
- 分发 / `spawn_columns`：`drone_module.py` + `plant_module.spawn_columns`；入口 `main.py`
- 迷宫生成/分叉 spawn：`maze_module.py`；入口 `main_maze.py`。肥料门槛仍是 `plant_module.min_crop_wealth()`
- 当前田块接线：`/tfwr-farm` 的 farm-layout.md

慢通常是语句 tick，不是少走路。调用/读变量是 0；贵的是下标、`if`、整表扫描。向日葵 max/known 增量改。不要为了省 tick 取消仙人掌折返。

改完加载 `/tfwr-sync-skills` 更新本文和 farm-layout，不要只改代码。

## 不要做

- 不要自动 `unlock()`。
- 不要自动加 Megafarm 档。工人数用 `max_drones()`，不要写死。
- 不要用 `set_world_size` 当扩地（会清场）。
- 不要把金子当成可种作物。
- 不要把向日葵、南瓜、仙人掌画回同一圈混种。
- 不要按列收光向日葵；按花瓣档位收，档位没收完不要补种。
- 不要把一列整列当成另一种作物去收。
- 不要为了省路禁止仙人掌折返。
